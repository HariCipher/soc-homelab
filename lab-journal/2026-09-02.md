## Broke
1. **DNS checks failed in the verify script** — all four of them, while DNS was
   actually fine. Root cause: `dig` / `bind-tools` is not installed on this host, so
   every DNS check failed on a missing binary rather than a bad answer.
   *Fix:* replaced with `scripts/verify/lib-dns.py`, a dependency-free DNS query.
   *Lesson:* a verification script that fails when its own tooling is missing is
   worse than no script — it reports the wrong layer.
2. **Mermaid diagram did not render on GitHub.** Root cause: nodes (`PF`) were
   referenced in edges declared *before* the subgraph that defined them, so the
   parser created them at top level and the subgraph then tried to reclaim them.
   *Fix:* declare all subgraphs and nodes first, all edges after. Also removed
   `<br/>`, `·` and `—` from labels and added a plain-text fallback.
